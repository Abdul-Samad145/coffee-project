# ⚡ Quick Start Guide

Get up and running with Artisan Coffee Collection in under 5 minutes!

## 🚀 Installation (30 seconds)

### Option 1: Download
1. Download the project files
2. Extract to a folder
3. Open `index.html` in your browser
4. Done! ✨

### Option 2: Git Clone
```bash
git clone <repository-url>
cd coffee-project
# Open index.html in your browser
```

### Option 3: Live Server (Recommended for Development)
```bash
# If you have VS Code with Live Server extension
1. Open folder in VS Code
2. Right-click index.html
3. Select "Open with Live Server"
```

## 🎯 First Steps (2 minutes)

### 1. Browse Coffees
- Scroll through the beautiful coffee cards
- Each card shows coffee name, roast type, origin, and tasting notes

### 2. Try the Search
- Click the search box at the top
- Type any coffee name (e.g., "espresso")
- Watch results filter in real-time

### 3. Filter by Roast
- Use the "Roast Type" dropdown
- Select Light, Medium, or Dark
- See only coffees of that roast type

### 4. Add to Favorites
- Click the heart icon on any coffee card
- The coffee is saved to your favorites
- Click "Show Favorites" to see only your favorites

### 5. View Details
- Click "View Details" on any coffee card
- See full information in a beautiful modal
- Click the X or press ESC to close

## 🎨 Customize Your Experience (2 minutes)

### Change Theme
1. Click the ⚙️ icon in the top-right corner
2. Choose from 5 beautiful themes:
   - **Classic** - Traditional coffee shop
   - **Modern** - Sleek minimalist
   - **Nature** - Earthy organic
   - **Sunset** - Warm vibrant
   - **Ocean** - Cool refreshing

### Change Layout
1. Open the theme panel (⚙️ icon)
2. Select "Layout Style"
3. Choose from:
   - **Grid** - Card grid (default)
   - **List** - Single column
   - **Masonry** - Pinterest style
   - **Compact** - Smaller cards

### Change Card Style
1. Open the theme panel
2. Select "Card Style"
3. Choose from:
   - **Elevated** - Drop shadow (default)
   - **Flat** - Minimalist
   - **Outlined** - Border only
   - **Glass** - Frosted glass effect

## ➕ Add Your Own Coffee (1 minute)

1. Click the "Add New Coffee" button
2. Fill in the form:
   - **Coffee Name** (required) - e.g., "Colombian Supreme"
   - **Roast Type** (required) - Light, Medium, or Dark
   - **Origin** (optional) - e.g., "Colombia"
   - **Tasting Notes** (optional) - e.g., "Chocolate, Nutty"
3. Click "Add Coffee"
4. Your coffee appears instantly!

## 🐛 Troubleshooting

### Coffee Not Appearing After Adding
- Check if filters are active
- Try "Show All" roasts
- Clear search box
- Refresh page if needed

### Theme Not Changing
- Make sure you clicked a theme button
- Check if browser supports CSS variables
- Try refreshing the page
- Clear browser cache

### Favorites Not Saving
- Check browser localStorage is enabled
- Not in private/incognito mode
- Browser has storage space
- Try different browser

### Animations Too Fast/Slow
- Open theme panel
- Adjust animation speed slider
- Find comfortable speed
- Setting is saved automatically

### Page Not Loading
- Check internet connection (for fonts)
- Try different browser
- Clear browser cache
- Check JavaScript is enabled
